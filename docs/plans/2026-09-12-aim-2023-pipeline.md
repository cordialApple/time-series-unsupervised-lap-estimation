# AiM 2023 Pipeline Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Enable 2023 AiM exports through validated inferred elapsed time, then execute all nine analysis notebooks without pooling cohorts.

**Architecture:** Dataset registry owns parser, clock, channel, and motion-policy configuration. Shared ingestion dispatches by registered CSV format, preserves source metadata and raw channel names, and generates elapsed time only in memory. Existing experiment runners consume dataset-specific channels and write dataset-scoped artifacts with provenance.

**Tech Stack:** Python 3.11+, csv, pandas, NumPy, SciPy, scikit-learn, PyTorch, Jupyter
